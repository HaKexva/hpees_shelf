# Contributing

## Pull requests and Linear

- **PR title format:** `[HAK-XX] <short description>`  
  Example: `[HAK-21] Add book tag filter in book page`

- **Link to one issue:** Each PR should link to **one** Linear issue — the **subissue** (child), not the main/parent issue.

- Create the PR before merging so Linear can link it. Put the issue key in the title (e.g. `[HAK-21]`) so the integration can associate the PR with the issue.
